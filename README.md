# InsanVideo Downloader

## Purpose

InsanVideo Downloader is an independently designed web application for downloading **publicly available** media content. The project focuses on a simple, original user experience with its own branding, UI, and architecture.

## Current Development Status

🚧 **Foundation stage.** The project structure, tooling, and documentation scaffolding are being established. No media downloading/extraction functionality exists yet.

## Planned Architecture

```
insanvideo-downloader/
├── frontend/   # React + Vite single-page application
├── backend/    # Node.js + Express API server
├── docs/       # Project documentation
└── tests/      # Integration and end-to-end tests
```

The frontend and backend are developed as separate applications that communicate over HTTP, allowing them to be built, tested, and deployed independently.

## Technologies

- **Frontend:** React, Vite, JavaScript
- **Backend:** Node.js, Express, JavaScript
- **Tooling:** Git, npm

## Development Roadmap

1. ✅ Project foundation (directory structure, tooling config, documentation)
2. ⬜ Frontend base UI (layout, routing, placeholder pages)
3. ⬜ Backend API skeleton (server setup, health checks, request validation)
4. ⬜ Public-media link handling and validation
5. ⬜ Media extraction/download implementation
6. ⬜ Error handling, rate limiting, and hardening
7. ⬜ Testing (unit, integration, end-to-end)
8. ⬜ Deployment
